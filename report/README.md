# Report

Figures, tables, and text for the final written report.

## Report outline

1. Objectives and relevance
2. Research: current portfolio models
3. Methodology: client profile, inputs, optimizer, rebalancing and shock response
4. Evaluation: benchmarks, backtesting, stress testing
5. Dashboard walkthrough and scenarios
6. Limitations and extensions
7. References

## Rules

- Save every figure as a file in `report/figures/` with a descriptive name (for example `efficient_frontier.png`).
- Every scenario shown in the dashboard needs a short written explanation here.
- Keep a running list of references in `report/references.md`.
